V19 — รวมภาพและเสียงใน index.html ไฟล์เดียว
อัปโหลด index.html แทนหน้าเกมเดิม ไม่ต้องใช้โฟลเดอร์ audio หรือ riders.png
เปิดผ่านลิงก์เว็บไซต์ด้วย Safari หรือ Chrome แล้วแตะทดสอบเสียง
ถ้าไม่มีเสียง ดูข้อความสถานะใต้ชื่อเกม เพิ่มระดับเสียงสื่อ และตรวจการเชื่อมต่อ Bluetooth
หน้าตัวอย่าง HTML ในแอปไฟล์อาจไม่ทำงานเหมือนเว็บเบราว์เซอร์
ยังไม่ได้ยืนยันสาเหตุบนอุปกรณ์ของผู้ใช้หรือทดสอบ Safari จริง
