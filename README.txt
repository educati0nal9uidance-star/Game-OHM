RETRO MOTO ครูเจต V18 — เสียงพากย์
20 ข้อ ข้อละ 20 วินาที
เสียงเริ่มเกม เล่นเมื่อกดเริ่ม
เสียงตอบถูก เล่นเมื่อตอบถูก และหยุดเสียงก่อนหน้าก่อนเสมอ
เสียงระหว่างเล่น เล่นหนึ่งครั้งในข้อ 3, 7, 11, 15, 19 หลังเริ่มข้อนั้น 5 วินาที ถ้าไม่มีเสียงอื่นเล่น
เสียงจบเกม เล่นเมื่อผ่านเส้นชัยแล้วแสดงผล
เสียงหยุดตามปุ่มพัก/สลับแท็บ และเปิดปิดได้ด้วยปุ่มเสียง
เริ่มต้นเปิดเสียง แต่เบราว์เซอร์ต้องได้รับการแตะปุ่มเริ่มก่อน
หากเบราว์เซอร์ปิดกั้นเสียง ให้แตะปุ่มเสียงปิดแล้วเปิดใหม่
แตก ZIP เก็บ index.html, riders.png และโฟลเดอร์ audio ไว้ด้วยกัน
GitHub Pages: อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด ไม่ใช่เฉพาะ index.html
ใช้ไฟล์ M4A ต้นฉบับทั้ง 4 ไฟล์ ไม่แก้ไขเนื้อหาเสียง
ทดสอบการเรียกเสียงและตรรกะใน Node; ยังไม่ได้ยืนยันการเล่นบน Safari จริง
