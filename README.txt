V20 เสียงพื้นหลังวน + เสียงแทรก
เสียงระหว่างเล่นวนทั้งเกมด้วยช่องเสียงแยก
ตอนตอบถูกลดเสียงพื้นหลังเหลือระดับเบาชั่วคราว คืนระดับปกติเมื่อพากย์จบ
ตอบผิดหรือหมดเวลา ใช้เอฟเฟกต์สังเคราะห์แทรกโดยไม่ลดเสียงพื้นหลัง
ยังไม่มีไฟล์เสียงพากย์ตอบผิดจากผู้ใช้
พักเกมหยุดเสียงทั้งหมดชั่วคราว เล่นต่อจากจุดเดิม
เมื่อจบหยุดพื้นหลังแล้วเล่นพากย์จบเกม
ภาพและเสียงฝังใน index.html อัปโหลดไฟล์เดียวแทนเดิม
ยังไม่ได้ตรวจด้วย Safari บนอุปกรณ์จริง
